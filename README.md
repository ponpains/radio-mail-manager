# ラジオ採用メール管理 v2

修正版です。

- 入力項目：番組 / 放送回 / 放送日 / ラジオネーム / コーナー / メール本文 / 要約 / URL / メモ
- 採用順は廃止
- 番組ごとの採用件数を上部に表示
- 放送日は詳細画面に表示
- 一覧：放送回 / ラジオネーム / コーナー / 本文（要約を表示）の4列
- 一覧は横スクロール不要
- 表見出しはスクロール時も固定
- 番組ごとに上部タブで切替
- CSV書き出し、JSONバックアップ／復元
- オフライン表示対応

GitHub Pagesを更新する場合は、このZIPの中身7ファイルを既存リポジトリへ上書きアップロードしてください。
