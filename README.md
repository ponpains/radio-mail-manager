# ラジオ採用メール管理（試作）

Androidでホーム画面に追加して使うことを想定したPWAです。

## 試作の機能
- スプレッドシート風の採用メール一覧
- 放送回・番組・コーナーで絞り込み
- タイトル・本文・ラジオネーム等の検索
- 採用メールの追加・編集・削除
- Podcast URLを詳細画面から直接開く
- JSONバックアップ／復元
- CSV書き出し
- Service Workerによるオフライン表示
- ローカルファースト（データは端末のブラウザ内に保存）

## Google Driveについて
この試作では、Google Driveへの自動同期ではなく「JSONバックアップを作ってGoogle Driveに保存」という安全な方式にしています。
Googleアカウントとの自動同期を行うには、ユーザー本人のGoogle OAuth設定（Google Cloud側の設定）が必要です。
試作を使って仕様を固めたあと、その部分を追加できます。

## Androidへの入れ方
PWAとしてインストールするにはHTTPSで公開する必要があります。
GitHub Pages / Netlify等にこのフォルダをそのまま公開し、AndroidのChromeで開いて「ホーム画面に追加」を選びます。
ローカルファイルを直接開くだけでも画面確認はできますが、Service WorkerとPWAインストールはHTTPS環境が必要です。
