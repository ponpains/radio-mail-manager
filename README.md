# ラジオメールマネージャー ver.11

ver.10をベースに、メモ→下書き→送信済の導線、下書き操作、番組タブ操作を強化しました。

## ver.11 の主な変更
- 下書き一覧の各項目右上に「…」メニューを追加
  - 下書きを編集
  - 下書きを削除
  - 下書きを複製
  - コピー
  - 送信済みに追加
- 下書き作成／編集画面の上部中央にリアルタイム文字数表示を追加
- メモ一覧の「…」に「下書きにする」を追加し、本文を下書きへコピー
- 「全件」タブを「送信済」へ名称変更
- 個別番組タブを長押しすると「名前の変更／削除／入れ替え」を表示
- 「入れ替え」で並べ替えモードに入り、番組タブを長押ししてドラッグすると順序を変更可能
- メモ追加画面は本文だけのシンプルなX風コンポーザーを継続
- メモ編集／詳細画面を下書き詳細に近い構成へ変更し「下書きにコピー」を実装
- 個別番組タブのサマリー操作を「メール → 検索 → 追加」の順に配置
- 送信済／採用の記録に入った日時を自動保存し、メール詳細タイトル右側・お気に入りの左に表示
- ポップアップ／ダイアログ外側タップで閉じる共通仕様を継続

## データ互換性
既存のlocalStorageデータを引き続き利用します。ver.11では番組タブの並び順と、送信済／採用へ入った日時を追加保存します。既存データについては保存済み日時から可能な範囲で補完します。
