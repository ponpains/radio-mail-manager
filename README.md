# ラジオメールマネージャー ver.16

ver.15の基本レイアウトと操作感を維持しつつ、採用表示・記録期間・ゴミ箱・番組設定サンプルを調整したバージョンです。

## ver.16 の主な変更
- 送信済一覧の採用表示
  - 採用済みメールは、番組名セルの右端にアクセントカラーの細い縦線を表示
  - 行全体の色付けは行わず、従来の一覧レイアウトを維持
- 記録の期間指定
  - 「すべて」「今年」「今年度」「過去30日」「指定」を追加
  - 「指定」では開始日・終了日を入力可能
  - 全体／番組別／コーナー別／ラジオネーム別／月別の各記録に期間条件を適用
- ゴミ箱
  - メール、下書き、メモの削除時は即時完全削除せずゴミ箱へ移動
  - ゴミ箱から復元、個別の完全削除、ゴミ箱を空にする操作が可能
  - 完全バックアップ／復元にもゴミ箱データを含める
- 番組設定のサンプル変更
  - デフォルトのラジオネーム：ラジオ猫
  - コーナー管理：ふつおた／リアクション

## 継続している主な仕様
- メモ → 下書き → 送信済 → 採用の管理
- 採用／不採用のトグル
- 番組設定・コーナー管理
- 完全バックアップ／復元
- 自動保存＋保存ボタン
- 表示項目カスタマイズ
- 横断検索
- CSV一括インポート／書き出し
- タブごとの独立ソート
