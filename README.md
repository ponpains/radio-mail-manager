# ラジオメールマネージャー ver.13

ver.12をベースに、タブごとのソート独立化、送信済一覧の省スペース化、詳細画面の本文優先表示、表示設定を追加しました。

## ver.13 の主な変更
- ソート状態をタブごとに独立
  - あるタブで並び替えても、他のタブの並び順には影響しません
  - タブごとのソート状態は端末内に保存されます
- 初期ソート
  - 「送信済」：投稿日時の新しい順
  - 「採用」および各番組タブ：従来どおり放送回の昇順
- 「送信済」一覧から「放送回」列を削除
  - 番組名／ラジオネーム／コーナー／本文の4列表示
- 下書き詳細を調整
  - ラジオネーム／コーナー入力欄をさらに小さく
  - 本文入力欄をメモ詳細に近い大きさまで拡大
- メール詳細をさらに本文優先に変更
  - 番組／放送回／放送日／ラジオネーム／コーナーの高さ、文字、余白を圧縮
  - 本文欄の最低高さを拡大
- 「⋯」メニューに「設定」を追加
  - 文字サイズ：小／中／大
  - タブサイズ：小／中／大
  - 一覧の高さ：コンパクト／標準／ゆったり
  - 詳細情報欄：コンパクト／標準／ゆったり
  - 設定は端末内に保存され、メール・メモのデータには影響しません
- ポップアップ／ダイアログ外側タップで閉じる共通仕様を継続

## ver.12からの表示変更履歴
- ver.12で「メールを追加」の要約／メモ欄を約28pxに短縮した仕様はそのまま維持しています。
- ver.13ではメール詳細のメタ情報をさらに圧縮しました。設定の「詳細情報欄」で後から表示密度を変更できます。

## データ互換性
メール、メモ、番組設定の既存localStorageキー／データ形式は変更していません。ver.12までのデータをそのまま利用できます。ver.13で追加したソート状態・表示設定は別のlocalStorageキーに保存されます。
