# ラジオメールマネージャー ver.12

ver.11をベースに、メール追加・詳細画面の省スペース化と、検索／ソート機能を強化しました。

## ver.12 の主な変更
- メモの新規追加画面は本文のみ。ラジオネーム／コーナー入力欄は表示しない仕様を明確化
- メール追加・メール詳細・メモ詳細・下書き詳細などの入力部分を灰色から白背景へ変更
- 「メールを追加」の本文欄を拡大
- 「メールを追加」の要約／メモ欄をさらに短縮
  - ver.11では要約／メモ欄は約42px
  - ver.12では約28pxへ変更
  - 元に戻す場合はstyles.cssのver.12セクションにある `#editDialog #summary, #editDialog #memo` を削除／調整すればver.11相当へ戻せます
- メール詳細の「放送回＋放送日」を1行、「ラジオネーム＋コーナー」を1行にまとめ、本文表示領域を拡大
- 送信済／採用タブの操作ボタンを個別番組タブと同じ右寄せ配置に統一
- すべてのメール系タブにソートボタン（↕）を追加
  - 放送回：昇順／降順
  - 追加日時：新しい順／古い順
  - ラジオネーム順
  - コーナー順
- 送信済／採用タブの検索フィルターに「番組」プルダウンを追加。ラジオネーム欄の左に配置
- ポップアップ／ダイアログ外側タップで閉じる共通仕様を継続

## データ互換性
localStorageのキーやメールデータ形式はver.11から変更していません。既存データをそのまま利用できます。今回追加したソート状態は一時的な表示設定で、メールデータ自体は変更しません。
