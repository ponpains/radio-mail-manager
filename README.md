# ラジオメールマネージャー ver.17

ver.16の基本仕様を維持しつつ、下書き／メモ詳細を「本文を広く見る」方向に調整したバージョンです。

## ver.17 の主な変更
- 下書き追加・編集画面から「ラジオネーム」「コーナー」の表示を削除
  - **既存データ自体は削除せず保持**。ver.16相当のUIへ戻す場合に復元可能
- 下書き詳細から「ラジオネーム」「コーナー」の表示を削除し、本文入力欄を拡大
- 下書き詳細下部を横一列に変更
  - 本文コピー／削除／送信済に追加／閉じる
  - 「送信済みに追加（全件タブに移動）」を「送信済に追加」に短縮
- メモ詳細にお気に入り（☆／★）を追加
- メモ一覧・下書き一覧で、お気に入り項目は文字数の横に★を表示
- メモ詳細・下書き詳細の本文入力欄を横幅いっぱいに近いレイアウトへ拡大

## 戻せるように保持する変更履歴
今回のver.17の下記変更は、ユーザー要望により**すぐver.16相当へ戻せるようにする対象**です。
1. 下書き追加／編集のラジオネーム・コーナー非表示
2. 下書き詳細のラジオネーム・コーナー非表示
3. 下書き詳細の本文欄拡大
4. 下書き詳細下部の横一列レイアウト
5. メモ詳細の本文欄横幅・高さ拡大

特に下書きのラジオネーム／コーナーは画面から隠すだけで、保存済み値を削除しません。

## 継続している主な仕様
- メモ → 下書き → 送信済 → 採用の管理
- 採用／不採用のトグル
- 番組設定・コーナー管理
- 完全バックアップ／復元
- 自動保存＋保存ボタン
- 表示項目カスタマイズ
- 横断検索
- CSV一括インポート／書き出し
- タブごとの独立ソート
- 記録の期間指定
- ゴミ箱
