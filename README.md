# ラジオメールマネージャー Web ver.26

ラジオ投稿の「メモ → 下書き → 送信済み → 採用」を端末内で管理するWeb/PWA版です。

## ver.26 主な変更

- メール追加時に要約が空でも、詳細画面の「要約」欄を常に表示して後から入力可能に修正。
- 検索ダイアログを上寄せし、キーワード入力欄を大型化。検索対象の初期値を「メモ」に変更。
- 複数選択アクションシートを含む全ダイアログ／ポップアップを、Androidの戻る操作で閉じる処理に統一。
- 番組追加UIを「番組設定」見出し横の＋ボタンから開く小さな追加ダイアログへ変更。

## データについて
データはブラウザの localStorage に保存します。別端末へ自動同期はしません。移行には完全バックアップJSONを使用してください。

## PWA公開
`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, アイコン類を同一ディレクトリでHTTPS配信してください。
