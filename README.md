# ラジオメールマネージャー ver.14

ver.13の見た目と基本導線をなるべく維持しながら、一般利用も想定した管理機能を追加したバージョンです。

## ver.14 の主な変更
- 番組設定を拡張
  - 投稿フォームURL
  - メールアドレス
  - デフォルトのラジオネーム
  - コーナー管理（1行1コーナー）
  - 放送曜日・推奨文字数・メール件名は追加していません
- コーナー管理
  - 番組設定で登録したコーナーを入力候補として利用できます
- 完全バックアップ／復元
  - メール、メモ、番組設定、コーナー、番組タブ順、ソート、表示設定、テーマを1つのJSONへ保存
  - 旧バージョンの「メール配列だけ」のJSONも復元可能
- 自動保存
  - 既存メモ／下書き／メールの編集中は内容を端末内へ自動保存
  - 新規作成途中は一時保存し、次回同じ作成画面で復元
  - 従来の「保存」ボタンも残しています
- 表示項目カスタマイズ
  - 設定からメール詳細の「番組／放送回／放送日／ラジオネーム／コーナー／要約／Podcast URL／メモ」の表示・非表示を選択可能
  - 非表示にしてもデータは削除されません
- 色付きラベル
  - 1件につき1つ、ラベル名＋色を設定可能
  - メモ、下書き、メールで利用できます
- 横断検索
  - 右上「⋯」の左に検索ボタンを追加
  - メモ、下書き、送信済、採用をまとめて検索できます
- 記録（統計）を拡張
  - 総送信数、採用数、採用率
  - 今月／今年の送信数
  - 下書き数、メモ数
  - 番組別、コーナー別集計
- CSV一括インポート
  - 「⋯」→「CSV読込」から追加読み込み
  - ver.14のCSV書き出し形式、および一般的な日本語列名に対応
- 採用フローを整理
  - 送信済タブの採用済メールの色付けを廃止
  - 送信済メール詳細の右上、星の左に「採用」ボタンを追加
  - 押すと同じメールが送信済に残ったまま「採用」タブと該当番組タブにも表示
  - 採用ボタンを押していないメールは送信済タブだけに表示

## データ互換性
既存の `radioMailManager.v3` のメールデータを維持し、ラベル等の新項目は未登録時に自動で初期値を補います。既存の番組設定もそのまま読み込み、新しい設定項目だけを追加できます。
