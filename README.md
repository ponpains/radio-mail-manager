# ラジオメールマネージャー ver.10

ver.9をベースに、一覧表示・メモ操作・下書き詳細・番組投稿導線を更新しました。

## ver.10 の主な変更
- メモ一覧の各項目右上に「…」メニューを追加
  - メモを編集
  - メモを削除
  - コピー
- メモ一覧の文字サイズと1行の高さをコンパクト化
- メモ編集画面は本文だけの軽い入力画面を継続し、ラジオネーム・コーナー欄は表示しない
- 下書き一覧を1行プレビュー＋作成日時＋文字数の表示に変更
  - 1行に収まらない本文は「…」で省略
  - ラジオネーム・コーナーは詳細画面だけで表示
- 下書き詳細のタイトル右側中央に文字数カウントを追加
- 「全件」「採用」タブの一覧の左端に「番組名」列を追加
- 個別番組タブの採用数欄に✉ボタンを追加
  - 番組設定の投稿フォームURLを優先して開く
  - URL未登録の場合は登録メールアドレスをメーラーで開く
- ダイアログ／ポップアップは外側タップで閉じることを共通仕様化
  - 現在存在するdialogだけでなく、今後追加されるdialogにも自動で適用されるように実装

## データについて
既存のlocalStorageデータはそのまま利用します。既存下書きに作成日時が保存されていない場合は、可能な範囲で既存IDから作成時刻を復元します。
