# ラジオメールマネージャー ver.15

ver.14の基本レイアウトと操作感を維持しつつ、採用状態・本文表示・記録画面を調整したバージョンです。

## ver.15 の主な変更
- ラベル機能を撤廃
  - メール、メモ、下書きのラベル入力・表示を削除
  - 横断検索やCSV書き出しからもラベルを除外
  - 旧データに残っているラベル情報はver.15起動時に取り除きます
- 採用ボタンをトグル式に変更
  - 送信済だけでなく、採用タブ・各番組タブのメール詳細にも採用ボタンを表示
  - 未採用のメールで押すと採用、採用済みメールで押すと採用解除
  - 採用解除すると採用タブ・番組タブから外れ、送信済タブには残ります
- 本文表示の修正
  - 一覧の「本文」列が要約ではなく実際の本文を表示するよう修正
  - 詳細画面で「状態」の下、Podcast URLの上にある編集欄を明示的に「本文」として扱うよう修正
  - 詳細で本文を編集すると一覧にも反映されます
- 記録画面を選択式に変更
  - 「全体」「番組別」「コーナー別」「ラジオネーム別」「月別」から表示内容を選択
  - 全体では送信数、採用数、採用率、今月、今年、下書き数、メモ数を表示

## 継続している主な仕様
- メモ → 下書き → 送信済 → 採用の管理
- 番組設定・コーナー管理
- 完全バックアップ／復元
- 自動保存＋保存ボタン
- 表示項目カスタマイズ
- 横断検索
- CSV一括インポート／書き出し
- タブごとの独立ソート

## 表示変更履歴
- ver.12：「メールを追加」の要約／メモ欄を約28pxへ短縮、本文欄を拡大
- ver.13：メール詳細のメタ情報をさらに圧縮。表示設定を追加
- ver.14：管理機能を拡張
- ver.15：ラベル撤廃、採用トグル、本文表示修正、記録選択式
