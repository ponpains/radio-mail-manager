# ラジオメールマネージャー Web ver.25

ラジオ投稿の「メモ → 下書き → 送信済み → 採用」を端末内で管理するWeb/PWA版です。

## ver.25 主な変更
- 完全バックアップJSONをクリップボードへコピーする「緊急バックアップをコピー」を追加。
- メール追加・編集画面からの「コーナー即追加」を廃止し、ver.22以前の入力方式へ戻しました。
- メモ／下書き検索は通常非表示にし、各タブ右上の検索ボタンから開く方式へ変更。
- 長押し時の複数選択メニュー／各種コンテキストメニューを visualViewport 基準で再配置し、画面内に収めるよう修正。収まらない場合はメニュー内スクロール。
- 「分析用に書き出す」を「詳細書き出し」へ名称変更。
- PWA対応を整理。HTTPSで公開するとホーム画面追加、standalone表示、Service Workerによる基本オフライン再表示が可能。
- 新規利用時の初期タブは「メモ」「下書き」「送信済」「採用」のみ。個別番組データは初期投入しません。
- 初回のみ、基本操作を説明する案内メモを1件追加。通常のメモとして削除可能。

## データについて
データはブラウザの localStorage に保存します。別端末へ自動同期はしません。移行には完全バックアップJSONを使用してください。

## PWA公開
`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, アイコン類を同一ディレクトリでHTTPS配信してください。


## ver.25
- 検索を右上の検索ダイアログへ統合（メモ／下書き／メール／横断）
- 複数選択アクションを画面下固定シートへ変更
- 初回「はじめに」を簡略化し、分析・緊急機能の説明を非表示化
- 番組設定から任意の専用タブを追加可能
- バックアップ・CSV関連7項目を「バックアップ・その他」に整理
